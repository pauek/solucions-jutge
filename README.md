
# Solucions als problemes del Jutge

Les meves solucions als problemes del Jutge. Durant els cursos 2024/25 i 2025/26 vaig ser coordinador de les assignatures de PRO1 i PRO2 del Grau en Enginyeria Informàtica a la Facultat d'Informàtica de Barcelona.

L'objectiu de publicar les solucions és donar el millor exemple possible als estudiants que estudien PRO1 i PRO2, per evitar les petites mancances que produeix tant la IA com repositoris d'ex-alumnes.

S'admeten _pull-requests_ amb correccions i solucions noves, que editaré adequadament perquè aquest repositori continuï essent modèlic.
